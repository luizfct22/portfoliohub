# PortfolioHUB - Meus Projetos e Estudos Acadêmicos
Bem-vindo ao meu portfólio acadêmico e profissional. Este espaço foi desenvolvido como parte da Entrega Intermediária para centralizar minhas atividades, organizar meus códigos e apresentar meu progresso técnico.

## Objetivo do Espaço
Centralizar meus trabalhos acadêmicos e projetos pessoais para construir um histórico prático sólido, aplicando boas práticas de organização de código e compartilhamento com o mercado de tecnologia.

## Estrutura de Diretórios
 * /projetos-acadêmicos: Destinado a trabalhos, relatórios e códigos desenvolvidos na faculdade.
 * /projetos-pessoais: Destinado a estudos autônomos, testes e portfólio individual.
 * index.html: Página principal publicada via GitHub Pages.
