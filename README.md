# PortfolioHUB

Meus projetos e estudos acadêmicos. Este espaço foi desenvolvido como parte da Entrega Intermediária para consolidar meus projetos e apresentar meu progresso técnico.

# Objetivo do Repositório
Centralizar projetos acadêmicos e pessoais para construir um perfil sólido, aplicando boas práticas de controle de versão (Git) e compartilhamento profissional.

# Estrutura de Diretórios
- `/projetos-acadêmicos`: Destinado a trabalhos, relatórios e códigos desenvolvidos na faculdade.
- `/projetos-pessoais`: Destinado a estudos autônomos, testes e portfólio individual.
- `index.html`: Página principal publicada via GitHub Pages.
